# Defect vs Bug

A defect is a problem in software where the actual behaviour differs from the specified or intended behaviour.

The word "bug" is commonly used informally to describe a software defect.

## Example

In the GreenChit practice application, suppose an expense claim is submitted, but the application displays an incorrect status instead of the status required by the scenario.

This could be a defect because the application is not behaving as intended. The scenario requirements must be checked before confirming it.

## Questions to Ask

- What should the application do?
- What actually happened?
- Can I reproduce the problem?
- What evidence supports reporting it?
