# What I Already Know About Testing

- Software testing helps check whether an application behaves as expected.
- Manual testing involves checking application functionality and comparing actual results with expected results.
- A defect is a problem in an application that may cause incorrect behaviour.
- Defects should be reported clearly so that another person can understand and reproduce them.
- I want to improve my ability to identify less obvious defects, such as confusing labels, usability problems, and slow response times.
