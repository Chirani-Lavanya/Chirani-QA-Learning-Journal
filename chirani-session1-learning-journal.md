## 1. What I Already Know

- I know that software testing checks whether an application behaves as expected.
- I know that test cases help testers check different scenarios.
- I know that defects can affect how an application works, but I want to learn how to identify and describe them clearly.

## 2. What I Want to Understand by Day 5

- Goal 1: Write a test case with preconditions, steps, and an expected result that another person can follow without asking for clarification.
- Goal 2: Write a defect report containing the environment, reproduction steps, expected result, and actual result.
- Goal 3: Record at least three AI verification examples and identify whether AI missed, got wrong, or invented information.

## 3. My Learning Style

- I learn best by practising concepts and trying examples myself, supported by reading and watching demonstrations.
- When I get stuck, I first try to understand the problem and investigate it before asking for help.
- One learning habit I want to build this week is writing down what I learn and verifying information before accepting it.
