# Security evidence folder

Place actual local outputs here after running the checks:

- `check-results.txt`
- redacted request and response bodies/headers
- `security-headers.txt`
- `zap-baseline-report.html`

No scan output has been fabricated. Never commit access tokens, passwords, real personal data or unredacted BOLA evidence. Report potential security findings privately to the reviewer/lead before creating a Restricted Jira ticket.
